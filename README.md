# ADG-ORAN: Attack-Defense Graphs for Open RAN Security Analysis

Code and data for the paper **"ADG-ORAN: Attack-Defense Graphs for Open RAN Security Analysis"**, accepted at **IEEE MILCOM 2026**.

ADG-ORAN builds a specification-driven Attack-Defense Graph (ADG) directly from the O-RAN Alliance WG11 security specifications (Release 005) and computes four graph-theoretic security metrics over it:

- **TPRS** (Topology-Propagated Risk Score) — component exposure via risk propagation over the O-RAN interface topology
- **CTI** (Cascading Threat Index) — threat amplification via Personalized PageRank on threat-escalation edges
- **DEI** (Defense Effectiveness Index) — control prioritization weighted by cascading risk and topology reach
- **SPI** (Security Posture Index) — overall posture as the fraction of criticality-weighted propagated risk eliminated by deployed controls

The resulting WG11 ADG contains **402 nodes** (10 assets, 282 threats, 110 controls) and **2,188 edges** (40 topology, 682 target, 817 enables, 649 mitigation).

## Repository Layout

```
src/       ADG construction, metrics, what-if scenarios, sensitivity analysis, figures
data/      Structured data extracted from the WG11 Release 005 specifications (JSON)
figures/   Paper figures (generated by src/visualize.py)
```

## Installation

```bash
python -m venv .venv && source .venv/bin/activate
pip install -r requirements.txt
```

Requires Python 3.10+.

## Reproducing the Paper Results

All scripts are run from `src/` (paths are anchored to the script location):

```bash
cd src
python main.py --all          # build graph + metrics + scenarios + figures
```

Or step by step:

```bash
cd src
python -c "from adg_builder import build_adg, print_graph_stats; print_graph_stats(build_adg())"
python metrics.py             # TPRS / CTI / DEI / SPI          (Sec. V-A)
python scenarios.py           # what-if scenarios S1–S5          (Sec. V-B)
python sensitivity.py         # parameter sensitivity sweeps     (Sec. V-C)
python visualize.py           # regenerate figures/ (Figs. 1–3)
```

Key baseline results:

| Result | Value |
|---|---|
| Security Posture Index (SPI) | 24.21 / 100 |
| Threats without direct control coverage | 187 / 282 (66.3%) |
| Top component by TPRS | SMO (55.22) |
| Top threat by CTI | T-SharedORU-57 (12.6× amplification) |
| Topology bottleneck (betweenness) | Near-RT RIC (0.34) |
| AI/ML threats with dedicated controls | 0 / 39 |

## Source Specifications

The graph is built from structured data extracted from the following O-RAN Alliance WG11 documents (Release 005), which are freely available from the [O-RAN Alliance specifications page](https://www.o-ran.org/specifications) and are **not redistributed** in this repository:

| Document | Number |
|---|---|
| Security Threat Modeling and Risk Assessment | O-RAN.WG11.TR.Threat-Modeling-R005-v08.00 |
| Security Requirements and Controls Specifications | O-RAN.WG11.TS.SRCS.0-R005-v14.00 |
| Study on Security for AI/ML in O-RAN | O-RAN.WG11.TR.AIML-Security.0-R005-v05.00 |
| Study on Security for O-Cloud | O-RAN.WG11.TR.O-CLOUD-Security.0-R005-v09.00 |
| Study on OAuth 2.0 Security | O-RAN.WG11.TR.OAuth2.0-Security.0-R005-v07.00 |
| SMO Security Analysis | O-RAN.WG11.TR.SMO-Security-Analysis.0-R005-v08.00 |
| Study on Supply Chain Management | O-RAN.WG11.TR.SCM.0-R005-v02.00 |
| Study on Zero Trust Architecture for O-RAN | O-RAN.WG11.TR.ZTA-R005-v05.00 |

The JSON files under `data/` contain threat, requirement, and control records derived from these documents for research purposes. All specification content is © O-RAN ALLIANCE e.V.
